## Demo Description 

### my-django-project 

As the name suggests , it's your own django project !

[Navigate to the Demo Page ↗](./my-django-project/)
- It demonstrates both `UI` and `API` counterparts of your system

**KeyPoints**
* Explains how to plug `django_gauth==1.0.0` in your project.
* Explains all the **Must Need To Know** features of `django_gauth`
    * Login Schemes
        * Seperate Page Redirection
            * Landing Page Customization Config
                * Custom Logo setting
                * Custom NavBar styles
            * Landing Page Change to External
        * Same Page Redirection
            * via Query Params
            * via Headers


### Sample1

It has a Django server ( for api's ) and a Flask Server ( for UI SSR rendered )

- the Flask Server can be think of as any React/Angular/Vue application .
